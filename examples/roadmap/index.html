weblink

Updated Jun 2, 2026

A deploy primitive built for agents. You point at a folder of website code, say the word, and get back a live URL you can open anywhere. No dashboards, no tokens, no setup.

It started as a single Claude Code skill wrapping the Vercel CLI. The bet is that the last mile of agent-written code, turning it into something shareable, is still built for humans clicking buttons. This closes that gap.

The path runs from a personal tool to a hosted product any agent can call. Below is how to use it today, and where it’s headed.

Using it

  1. Install once. Grab the Vercel CLI and sign in.npm i -g vercel && vercel login
  2. Point Claude at your folder. In Claude Code, reference the website folder with @ and ask to deploy.@my-site deploy this website
  3. Get a link. Claude hands back a live, public URL on weblink.dev you can open or share anywhere.Live at https://my-site-a1b2.weblink.dev
  4. Change it anytime. Edit the files and ask to update, and the same clean URL refreshes in place.“update the my-site page” → https://my-site.weblink.dev

Roadmap

Personal skill

Shipped

The proof that the gesture feels like magic.

  • A Claude Code skill wrapping the Vercel CLI: your account, throwaway public URLs.
  • Stages a clean copy of the folder, so your source is never touched.
  • Auto-disables Vercel’s login gate, so every link is genuinely public on the first try.
  • Static or framework apps, auto-detected.

Open source

Stage 1 · Next

Release it as a plugin: research disguised as a product.

  • Bring-your-own-Vercel: anyone installs it and plugs in their own account. Zero infra cost.
  • Distributed via the Claude Code plugin marketplace and GitHub.
  • Exposed as an MCP server, so it works from any agent, not just Claude Code.
  • Learn what people actually ask a deploy tool to do.

Hosted backend

Stage 2 · Later

The real product: you own the hosting.

  • The user just says “deploy” and gets a URL on your platform. No account, no token, no DNS.
  • Built on Cloudflare Workers / Pages + R2: cheap, edge-fast, DDoS-protected.
  • Static-first. Free tier (ephemeral) plus paid: persistence, custom domains, password protection.
  • Abuse handling, TTLs, and cost caps are the actual business, and the moat.

Builds & public API

Stage 3 · Later

The deploy API for the agent era.

  • Sandboxed framework builds: Next.js, Vite, and friends.
  • A public REST API so any app or agent can deploy programmatically.
  • Usage-based tier for other agent products to build on.
  • “Vercel for agents,” unbundled from any one builder.
